# Leasing Dashboard

A lightweight static dashboard that showcases leasing projects with advanced filters and a light / dark theme toggle.

## Getting started

Open `index.html` in your browser. The dashboard will load sample data and provide three filters:

- **Developer**
- **Development**
- **Funding Bank**

Use the toggle in the header to switch between dark and light modes. The app respects your system light-mode preference on first load.
